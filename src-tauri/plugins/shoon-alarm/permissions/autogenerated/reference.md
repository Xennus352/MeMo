## Default Permission

Allows scheduling and cancelling Shoon speaking alarms (locked-phone reminder voice), speaking text aloud through the device TTS, and opening the notification settings page.

#### This default permission set includes the following:

- `allow-schedule-shoon-alarm`
- `allow-cancel-all-shoon-alarms`
- `allow-speak-text`
- `allow-open-notification-settings`
